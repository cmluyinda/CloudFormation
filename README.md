# CloudFormation Learning Project

## Overview
This repository documents my journey learning AWS CloudFormation and Infrastructure as Code (IaC).

## Learning Objectives
- Understand Infrastructure as Code.
- Write CloudFormation templates using YAML.
- Deploy and manage AWS resources through templates.
- Practise infrastructure automation and version control.
- Apply AWS security and cost-management best practices.

## Project Structure
- `templates/` – CloudFormation templates.
- `parameters/` – Configuration and parameter files.
- `documentation/` – Learning notes and project documentation.
